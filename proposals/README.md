# Proposals

Anything that changes what a conforming implementation must do goes through a
**TIP**, a Touchstone Improvement Proposal, and TIPs live here. The process —
the five required sections, and the rule that nothing reaches final without both
a reference implementation and a conformance vector — is in
[`../CONTRIBUTING.md`](../CONTRIBUTING.md).

One file per proposal, named for its pull request number once it has one:
`0042-binding-region-tiebreak.md`.
